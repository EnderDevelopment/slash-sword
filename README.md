# Roblox Sword Slash Script

This project contains a LocalScript for a sword to slash in Roblox. It includes a LocalScript for the slashing animation and a damage system to handle the damage dealt by the sword.

## Install

1. Open Roblox Studio and create a new place or open an existing one.
2. Insert a sword model into your game.
3. In the Explorer, navigate to the sword model.
4. Create a new LocalScript inside the sword model.
5. Copy the contents of `SlashSword.LocalScript.lua` into the LocalScript.
6. Replace "Sword" with the actual name of your sword in the script.
7. Replace "YOUR_ANIMATION_ID" with the actual animation ID for the slashing animation.
8. Save and play the game to test the sword slashing functionality.

## Use

1. Place the `SlashSword.LocalScript.lua` file inside the sword model in Roblox Studio.
2. Place the `DamageSystem.LocalScript.lua` file inside the sword model in Roblox Studio.
3. Make sure to replace the placeholder animation ID with your actual animation ID in the `SlashSword.LocalScript.lua` file.
