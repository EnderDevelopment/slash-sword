# Sword Slash System

## LocalScript

Place the `SlashSword.LocalScript.lua` file inside the sword model in Roblox Studio.

## Damage System

Place the `DamageSystem.LocalScript.lua` file inside the sword model in Roblox Studio.

## Animation

Make sure to replace the placeholder animation ID with your actual animation ID in the `SlashSword.LocalScript.lua` file.
